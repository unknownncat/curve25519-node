# Código de Conduta

Este projeto adota o [Contributor Covenant Code of Conduct 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Nosso compromisso

Queremos uma comunidade respeitosa, inclusiva e colaborativa para todas as pessoas.

## Comportamento esperado

- Respeito em discussões técnicas.
- Críticas focadas em código e argumentos, não em pessoas.
- Abertura para feedback e correções.

## Comportamento inaceitável

- Assédio, discriminação, insultos ou ataques pessoais.
- Publicação de informações privadas sem permissão.
- Conduta que comprometa a segurança ou o bem-estar da comunidade.

## Reporte

Para reportar violações, abra uma issue com o mínimo necessário e solicite contato privado com os mantenedores.
